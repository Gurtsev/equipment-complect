# Безопасность изображений оборудования

Frontend и RLS закрывают разные уровни загрузки:

- frontend принимает только `image/*` размером не более 10 МБ;
- миграция `026_storage_and_allowlist_security.sql` разрешает запись в bucket
  только ролям `admin` и `operator`;
- публичность bucket влияет только на чтение уже загруженных изображений.

## Настройка bucket на self-hosted Supabase

В Supabase Studio открыть Storage → `equipment-images` → настройки bucket и
установить:

- Public bucket: включено;
- Maximum file size: `10 MB`;
- Allowed MIME types: `image/*`.

Ограничения bucket являются серверной защитой размера и типа. Прямое изменение
таблиц служебной схемы `storage` не используется.

## Проверка после миграции 026

1. Под `viewer` загрузка должна завершаться отказом RLS.
2. Под `operator` JPEG/PNG меньше 10 МБ должен загружаться.
3. PDF должен отклоняться до сетевого запроса.
4. Изображение больше 10 МБ должно отклоняться до сетевого запроса.
5. Страница управления allowlist доступна admin; прямой SELECT под operator/viewer
   не должен возвращать строки.
