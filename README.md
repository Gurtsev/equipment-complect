# Equipment Complect

Система учёта студийного оборудования — SPA для каталогизации, отслеживания статуса и истории перемещений техники.

## Стек

- **React 18** + **TypeScript** + **Vite**
- **Ant Design 5** — UI-компоненты
- **qrcode.react** — генерация QR-кодов
- Данные хранятся в памяти, без бэкенда и базы данных

## Запуск

```powershell
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

```powershell
npm run build    # сборка в dist/
npm run preview  # предпросмотр сборки
```

## Возможности

- **Каталог оборудования** — список с поиском по модели или инвентарному номеру, фильтрация по категориям (камеры, микрофоны, свет, компьютеры, аудио, оптика, аксессуары)
- **Карточка оборудования** — фото, характеристики, инвентарный и серийный номера, комплектация
- **Управление статусом** — смена статуса (`В Работе`, `На Складе`, `В Ремонте`, `Списано`, `В Пути`) и местоположения с сохранением в историю
- **История перемещений** — хронологическая таблица всех изменений статуса
- **Добавление оборудования** — форма в Drawer с поддержкой произвольной комплектации
- **QR-коды** — генерация и просмотр QR для каждой единицы оборудования (кодирует `equipment:<id>`)

## Структура проекта

```
src/
  models/          # Equipment, EquipmentRepository — типы и бизнес-логика
  data/            # Seed-данные, синглтон repository
  components/
    CatalogSidebar/        # Левая панель: поиск, фильтр, список
    EquipmentDetail/       # Правая панель: карточка, статус, история
    CreateEquipmentDrawer/ # Форма добавления оборудования
  App.tsx          # Корневой layout
```
