## ✅ Этап 3 — Коллаборация

Данные переезжают на сервер. Появляются пользователи и роли.

### ✅ 3.1 Бэкенд — Supabase (PostgreSQL + готовый API)
- Таблицы: equipment, equipment_history, projects, project_equipment
- Сервисный слой `src/services/`: equipmentService, historyService, projectService
- Переменные окружения: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`

### ✅ 3.1.1 Supabase Storage — изображения оборудования
- Публичный bucket `equipment-images`
- `<Upload>` в форме оборудования, файл → Storage, URL → БД

### ✅ 3.2 Авторизация и роли
- Вход по email + пароль (Supabase Auth)
- Роли: Администратор / Оператор / Наблюдатель
- RLS включён на всех таблицах и Storage

| Роль | Права |
|---|---|
| Администратор | Всё: создание, редактирование, удаление, управление пользователями |
| Оператор | Добавление оборудования, смена статуса, редактирование, работа с проектами |
| Наблюдатель | Только просмотр |

## Этап 4 — Доступность и многопользовательность

### 4.1 Деплой на Vercel
- Подключить GitHub репозиторий к Vercel
- Настроить переменные окружения (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`)
- Система доступна по постоянной ссылке с любого устройства
- Решает проблему VPN/localhost — все работают через одну публичную ссылку

### 4.2 Управление пользователями
- Страница администратора: список сотрудников с ролями
- Приглашение по email (Supabase `inviteUserByEmail`)
- Смена роли, деактивация аккаунта
- Без этого новых пользователей можно добавить только через Supabase Dashboard

### 4.3 Синхронизация в реальном времени
- Supabase Realtime subscriptions на таблицы equipment, projects
- Изменения одного пользователя мгновенно отображаются у всех
- Нужна после 4.1 — смысл появляется когда пользователей несколько

### 4.4 История с привязкой к аккаунту
- `user_id uuid references auth.users` в таблице `equipment_history`
- В истории показывается имя из `profiles`, а не только текст «ответственный»

### 4.5 Коллаборация по проектам
- Защита от конфликтов в реальном времени
- Уведомление при попытке занять уже занятую единицу
- Календарный вид: какое оборудование занято в конкретный день
- История на уровне проекта: кто что добавил / убрал
